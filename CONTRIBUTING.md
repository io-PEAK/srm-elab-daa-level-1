## Contributing Guidelines

Thanks for your interest in contributing.

This repository is focused on maintaining a structured collection of DAA ELAB questions along with their solutions. Please follow the guidelines below to ensure consistency.

---

### 📌 What to contribute

✅ You can open a PR for:

* Adding a new question along with its solution

Each contribution must represent a **complete unit**:

> One file = One question + its solution

---

### 📁 File Naming Convention

* The file name must be based on the **first line of the question**

* It should be **descriptive enough to distinguish it from existing questions**

* Ensure the name is **unique within the repository**

* Use the appropriate extension:

  * `.c` for C
  * `.cpp` for C++

---

### 🧾 File Content Format

Each file should:

* Start with the **full question (first line = same as file name)**
* Include the **complete solution code**
* Maintain clean and readable formatting

---

### ❌ What NOT to submit as PR

Do NOT open PRs for:

* Minor fixes (typos, syntax errors, missing brackets, formatting)
* Small edits to existing files

---

### 🛠 Reporting Issues

For any problems in existing files:

* Open an **Issue instead of a PR**

This includes:

* Minor fixes (typos, syntax errors, formatting)
* Small edits or corrections
* Missing brackets or similar issues

Use appropriate labels such as:

* `minor-fix`
* `bug`

These will be handled separately.

---

### 🔁 Duplicates

Before submitting:

* Check if the question already exists

If a duplicate is found:

* The PR/Issue will be closed with a `duplicate` label

---

> [!NOTE]
>
> - Ensure your submission is not already present
> - Follow the repository structure and conventions strictly
> - For minor fixes in existing files, open an issue instead of a PR

---

Thanks for contributing and helping improve the repository!
